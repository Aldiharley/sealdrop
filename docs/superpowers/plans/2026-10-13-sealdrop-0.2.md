# sealdrop 0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship sealdrop 0.2: a Rust core + CLI that packages any file/folder into an age-encrypted bundle with a signed manifest, hardened extraction, generated passphrases, optional Argon2id, timed release via a self-hosted key-release service, and a Tauri desktop app in a pastel neumorphic style.

**Architecture:** A Cargo workspace. `sealdrop-core` holds all logic behind small modules with trait seams (`Progress`, `ReleaseFetch`) so the CLI, the Tauri commands and the tests all call the same functions. `sealdrop-release` is a separate axum + SQLite binary. The desktop app is React 19 + Vite + hand-written CSS over thin Tauri commands.

**Tech Stack:** Rust 1.96, `age` 0.12.1 (features `armor`, `plugin`), `age-core` 0.12, `minisign` 0.10, `argon2` 0.6, `chacha20poly1305` 0.11, `tar` 0.4, `clap` 4, `ureq` 3, `axum` 0.8, `rusqlite` 0.40 (bundled), Tauri 2.12, React 19, Vite 8, TypeScript.

Spec: `docs/superpowers/specs/2026-10-13-sealdrop-core-cli-desktop-design.md`. Read it before starting any task.

## Global Constraints

- Licence Apache-2.0; never copy code from Picocrypt or Kryptor (GPL-3.0).
- Never implement anything below the age format layer; use the `age` crate for all cryptography except the two custom stanzas (`sealdrop-argon2id`, `sealdrop-release`), which only wrap the age file key.
- Pin `tauri = "2.12"` and `tauri-build = "2.7"` (cargo search shows 3.0 alphas; do not use them).
- scrypt work factor: default logN 18, "high" logN 20, decrypt refuses logN > 22.
- Argon2id profiles: desktop t=1 m=2 GiB p=4; compat t=3 m=256 MiB p=4; decrypt bounds t ≤ 10, m ≤ 2 GiB, p ≤ 8.
- Passphrases: EFF long list, 6 words minimum (77.5 bits); BIP-39, 10 words minimum (110 bits). Word lists: EFF sha256 `addd35536511597a02fa0a9ff1e5284677b8883b83e986e43f15a3db996b903e` (7776 lines), BIP-39 english sha256 `2f5eed53a4727b4bf8880d8f3f199efc90e58503646d9ff8eff3a2ed3b24dbda` (2048 lines).
- Plugin allow-list: `yubikey`, `fido2prf`, `se`, `tpm`.
- Extraction limits default: 100,000 entries, 64 GiB total, 1 MiB `meta.json`.
- Passphrase and timed-release stanzas stand alone in the age header.
- CLI exit codes: 0 ok, 1 error, 2 verification failed, 3 policy refused.
- Secrets in `secrecy::SecretString` or `zeroize::Zeroizing`; no secret in logs, `Debug` output or files other than the key store.
- UI copy for timed release (verbatim): "The recipient can open this only within [window] after they first open it. This does not protect the contents once decrypted." and "Expiry applies to the encrypted package only; nothing can recall a file after it has been decrypted."
- Conventional commit messages; every commit ends with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`; push to `origin main` after each task.
- Home directory contains a space: always quote paths in shell commands.

```rust
//! SHA-256 helpers used for meta.json, manifests and verification.

use std::fs::File;
use std::io::{self, Read, Write};
use std::path::Path;

use sha2::{Digest, Sha256};

use crate::Result;

/// Writer that hashes everything passing through it.
pub struct HashingWriter<W: Write> {
    inner: W,
    hasher: Sha256,
    bytes: u64,
}

impl<W: Write> HashingWriter<W> {
    pub fn new(inner: W) -> Self {
        Self { inner, hasher: Sha256::new(), bytes: 0 }
    }

    /// Returns `(inner, sha256_hex, bytes_written)`.
    pub fn finish(self) -> (W, String, u64) {
        (self.inner, hex::encode(self.hasher.finalize()), self.bytes)
    }
}

impl<W: Write> Write for HashingWriter<W> {
    fn write(&mut self, buf: &[u8]) -> io::Result<usize> {
        let n = self.inner.write(buf)?;
        self.hasher.update(&buf[..n]);
        self.bytes += n as u64;
        Ok(n)
    }
    fn flush(&mut self) -> io::Result<()> {
        self.inner.flush()
    }
}

pub fn sha256_hex(data: &[u8]) -> String {
    hex::encode(Sha256::digest(data))
}

/// Streams a file through SHA-256. Returns `(hex, size)`.
pub fn sha256_file(path: &Path) -> Result<(String, u64)> {
    let mut f = File::open(path)?;
    let mut hasher = Sha256::new();
    let mut buf = vec![0u8; 1 << 16];
    let mut total = 0u64;
    loop {
        let n = f.read(&mut buf)?;
        if n == 0 {
            break;
        }
        hasher.update(&buf[..n]);
        total += n as u64;
    }
    Ok((hex::encode(hasher.finalize()), total))
}
```

```rust
//! Streams a file or folder into a tar with `sealdrop/meta.json` first.

use std::fs::File;
use std::io::Write;
use std::path::{Component, Path};

use serde::{Deserialize, Serialize};
use tar::{Builder, EntryType, Header};
use walkdir::WalkDir;

use crate::hashing::{sha256_file, HashingWriter};
use crate::{Error, Result, TOOL};

pub const META_PATH: &str = "sealdrop/meta.json";
pub const PAYLOAD_PREFIX: &str = "sealdrop/payload/";
pub const META_FORMAT: &str = "sealdrop/1";

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
pub struct FileEntry {
    /// Relative path under `sealdrop/payload/`, `/`-separated, starts with `root`.
    pub path: String,
    pub size: u64,
    pub sha256: String,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Meta {
    pub format: String,
    pub tool: String,
    pub created: String,
    /// Top-level name inside the payload (file name or folder name).
    pub root: String,
    pub files: Vec<FileEntry>,
}

#[derive(Debug, Clone)]
pub struct PackReport {
    pub meta: Meta,
    pub total_bytes: u64,
    pub tar_sha256: String,
}

fn rel_string(root_name: &str, rel: &Path) -> Result<String> {
    let mut parts = vec![root_name.to_string()];
    for c in rel.components() {
        match c {
            Component::Normal(s) => parts.push(s.to_string_lossy().into_owned()),
            Component::CurDir => {}
            other => return Err(Error::Other(format!("unexpected path component {other:?}"))),
        }
    }
    Ok(parts.join("/"))
}

/// Packs `input` (file or folder) into `out`. Two passes: hash first (so `meta.json`
/// can be the first entry), then stream the tar. Symlinks are skipped. Returns the
/// writer so callers (the encryptor) can finish it.
pub fn pack<W: Write>(input: &Path, out: W) -> Result<(PackReport, W)> {
    let md = std::fs::metadata(input)?;
    let root_name = input
        .file_name()
        .ok_or_else(|| Error::Other("input has no file name".into()))?
        .to_string_lossy()
        .into_owned();

    // Pass 1: enumerate, sorted, hash.
    let mut files: Vec<(std::path::PathBuf, FileEntry)> = Vec::new();
    let mut dirs: Vec<String> = Vec::new();
    if md.is_file() {
        let (sha256, size) = sha256_file(input)?;
        files.push((input.to_path_buf(), FileEntry { path: root_name.clone(), size, sha256 }));
    } else if md.is_dir() {
        for entry in WalkDir::new(input).follow_links(false).sort_by_file_name() {
            let entry = entry.map_err(|e| Error::Other(e.to_string()))?;
            let ft = entry.file_type();
            let rel = entry.path().strip_prefix(input).unwrap();
            if rel.as_os_str().is_empty() {
                continue;
            }
            if ft.is_symlink() {
                continue; // never packed; spec 4.1
            }
            let rel_s = rel_string(&root_name, rel)?;
            if ft.is_dir() {
                dirs.push(rel_s);
            } else if ft.is_file() {
                let (sha256, size) = sha256_file(entry.path())?;
                files.push((entry.path().to_path_buf(), FileEntry { path: rel_s, size, sha256 }));
            }
        }
    } else {
        return Err(Error::Other("input is neither a file nor a folder".into()));
    }

    let meta = Meta {
        format: META_FORMAT.into(),
        tool: TOOL.into(),
        created: chrono::Utc::now().format("%Y-%m-%dT%H:%M:%SZ").to_string(),
        root: root_name.clone(),
        files: files.iter().map(|(_, f)| f.clone()).collect(),
    };
    let meta_bytes = serde_json::to_vec_pretty(&meta).map_err(|e| Error::Manifest(e.to_string()))?;

    // Pass 2: write tar through a hashing writer.
    let hw = HashingWriter::new(out);
    let mut tar = Builder::new(hw);
    let now = chrono::Utc::now().timestamp() as u64;

    let mut h = Header::new_ustar();
    h.set_size(meta_bytes.len() as u64);
    h.set_mode(0o644);
    h.set_mtime(now);
    h.set_entry_type(EntryType::Regular);
    tar.append_data(&mut h, META_PATH, &meta_bytes[..])?;

    if md.is_dir() {
        let mut h = Header::new_ustar();
        h.set_size(0);
        h.set_mode(0o755);
        h.set_mtime(now);
        h.set_entry_type(EntryType::Directory);
        tar.append_data(&mut h, format!("{PAYLOAD_PREFIX}{root_name}"), std::io::empty())?;
        for d in &dirs {
            let mut h = Header::new_ustar();
            h.set_size(0);
            h.set_mode(0o755);
            h.set_mtime(now);
            h.set_entry_type(EntryType::Directory);
            tar.append_data(&mut h, format!("{PAYLOAD_PREFIX}{d}"), std::io::empty())?;
        }
    }

    let mut total = 0u64;
    for (abs, fe) in &files {
        let mut h = Header::new_ustar();
        h.set_size(fe.size);
        h.set_mode(0o644);
        h.set_mtime(now);
        h.set_entry_type(EntryType::Regular);
        let f = File::open(abs)?;
        tar.append_data(&mut h, format!("{PAYLOAD_PREFIX}{}", fe.path), f)?;
        total += fe.size;
    }

    let hw = tar.into_inner()?;
    let (w, tar_sha256, _) = hw.finish();
    Ok((PackReport { meta, total_bytes: total, tar_sha256 }, w))
}
```

```rust
use std::collections::HashMap;
use std::fs::{self, File};
use std::io::{self, Read, Write};
use std::path::{Path, PathBuf};

use crate::hashing::HashingWriter;
use crate::pack::{Meta, META_FORMAT, META_PATH, PAYLOAD_PREFIX};
use crate::{Error, Result};

pub const META_MAX_BYTES: u64 = 1024 * 1024;

#[derive(Debug, Clone)]
pub struct Limits {
    pub max_entries: u64,
    pub max_bytes: u64,
    pub max_file_bytes: u64,
}

impl Default for Limits {
    fn default() -> Self {
        Self { max_entries: 100_000, max_bytes: 64 << 30, max_file_bytes: 64 << 30 }
    }
}

#[derive(Debug, thiserror::Error, PartialEq, Eq)]
pub enum ExtractError {
    #[error("forbidden entry type for {0}")]
    ForbiddenEntry(String),
    #[error("bad path {0}")]
    BadPath(String),
    #[error("first entry must be sealdrop/meta.json")]
    MetaMissing,
    #[error("meta.json too large")]
    MetaTooLarge,
    #[error("meta.json invalid: {0}")]
    MetaInvalid(String),
    #[error("too many entries")]
    TooManyEntries,
    #[error("too many bytes")]
    TooManyBytes,
    #[error("hash mismatch for {0}")]
    HashMismatch(String),
    #[error("file listed in meta.json missing from archive: {0}")]
    MissingFile(String),
    #[error("file not listed in meta.json: {0}")]
    UnlistedFile(String),
    #[error("entry root {0} does not match meta root")]
    WrongRoot(String),
}

#[derive(Debug, Clone)]
pub struct ExtractReport {
    pub root: PathBuf,
    pub files: usize,
    pub bytes: u64,
    pub meta: Meta,
}

const WINDOWS_RESERVED: &[&str] = &[
    "CON", "PRN", "AUX", "NUL", "COM1", "COM2", "COM3", "COM4", "COM5", "COM6", "COM7", "COM8",
    "COM9", "LPT1", "LPT2", "LPT3", "LPT4", "LPT5", "LPT6", "LPT7", "LPT8", "LPT9",
];

/// Validates a tar entry path and returns it relative to `sealdrop/payload/`.
pub fn check_path(p: &str) -> std::result::Result<String, ExtractError> {
    let bad = || ExtractError::BadPath(p.to_string());
    if p.contains('\0') || p.contains('\\') || p.contains(':') || p.starts_with('/') {
        return Err(bad());
    }
    let rel = p.strip_prefix(PAYLOAD_PREFIX).ok_or_else(bad)?;
    if rel.is_empty() {
        return Err(bad());
    }
    for comp in rel.split('/') {
        if comp.is_empty() || comp == "." || comp == ".." {
            return Err(bad());
        }
        // Windows strips trailing spaces/dots, so `CON ` and `a.` alias `CON` and `a`.
        if comp.ends_with(' ') || comp.ends_with('.') {
            return Err(bad());
        }
        if comp.chars().any(|c| (c as u32) < 0x20 || "<>\"|?*".contains(c)) {
            return Err(bad());
        }
        let stem = comp.split('.').next().unwrap_or("").to_ascii_uppercase();
        if WINDOWS_RESERVED.contains(&stem.as_str()) {
            return Err(bad());
        }
    }
    Ok(rel.to_string())
}

fn entry_path_string(entry: &tar::Entry<'_, impl Read>) -> std::result::Result<String, ExtractError> {
    let p = entry.path().map_err(|e| ExtractError::BadPath(e.to_string()))?;
    let s = p.to_string_lossy().into_owned();
    // On Windows the tar crate may yield backslashes for GNU long names; normalise only
    // for the META check; payload paths with backslashes are rejected by check_path.
    Ok(s)
}

/// Extracts a sealdrop tar stream into `out_dir/<root>`, verifying every file hash.
pub fn extract<R: Read>(r: R, out_dir: &Path, limits: &Limits, overwrite: bool) -> Result<ExtractReport> {
    let mut archive = tar::Archive::new(r);
    archive.set_overwrite(false);
    archive.set_preserve_permissions(false);
    archive.set_unpack_xattrs(false);
    let mut entries = archive.entries()?;

    // 1. meta.json must be first.
    let mut first = entries.next().ok_or(ExtractError::MetaMissing)??;
    if entry_path_string(&first)? != META_PATH || !first.header().entry_type().is_file() {
        return Err(ExtractError::MetaMissing.into());
    }
    if first.header().size()? > META_MAX_BYTES {
        return Err(ExtractError::MetaTooLarge.into());
    }
    let mut meta_bytes = Vec::new();
    first.take(META_MAX_BYTES + 1).read_to_end(&mut meta_bytes)?;
    if meta_bytes.len() as u64 > META_MAX_BYTES {
        return Err(ExtractError::MetaTooLarge.into());
    }
    let meta: Meta = serde_json::from_slice(&meta_bytes)
        .map_err(|e| ExtractError::MetaInvalid(e.to_string()))?;
    if meta.format != META_FORMAT {
        return Err(ExtractError::MetaInvalid(format!("unknown format {}", meta.format)).into());
    }
    check_path(&format!("{PAYLOAD_PREFIX}{}", meta.root))?;
    for f in &meta.files {
        let rel = check_path(&format!("{PAYLOAD_PREFIX}{}", f.path))?;
        if rel.split('/').next() != Some(meta.root.as_str()) {
            return Err(ExtractError::WrongRoot(f.path.clone()).into());
        }
    }
    let expected: HashMap<&str, &crate::pack::FileEntry> =
        meta.files.iter().map(|f| (f.path.as_str(), f)).collect();

    // 2. Temp dir inside out_dir so the final rename is atomic on the same volume.
    fs::create_dir_all(out_dir)?;
    let final_path = out_dir.join(&meta.root);
    if final_path.exists() && !overwrite {
        return Err(Error::Exists(final_path));
    }
    let tmp = tempfile::Builder::new().prefix(".sealdrop-").tempdir_in(out_dir)?;

    let mut n_entries = 1u64;
    let mut n_bytes = 0u64;
    let mut seen: HashMap<String, ()> = HashMap::new();

    for entry in entries {
        let mut entry = entry?;
        n_entries += 1;
        if n_entries > limits.max_entries {
            return Err(ExtractError::TooManyEntries.into());
        }
        let raw = entry_path_string(&entry)?;
        let rel = check_path(&raw)?;
        if rel.split('/').next() != Some(meta.root.as_str()) {
            return Err(ExtractError::WrongRoot(rel).into());
        }
        let dest = tmp.path().join(&rel);
        let et = entry.header().entry_type();
        if et.is_dir() {
            fs::create_dir_all(&dest)?;
            continue;
        }
        if !et.is_file() {
            return Err(ExtractError::ForbiddenEntry(rel).into());
        }
        let fe = *expected.get(rel.as_str()).ok_or_else(|| ExtractError::UnlistedFile(rel.clone()))?;
        let size = entry.header().size()?;
        if size != fe.size || size > limits.max_file_bytes {
            return Err(ExtractError::HashMismatch(rel).into());
        }
        n_bytes += size;
        if n_bytes > limits.max_bytes {
            return Err(ExtractError::TooManyBytes.into());
        }
        if let Some(parent) = dest.parent() {
            fs::create_dir_all(parent)?;
        }
        let mut hw = HashingWriter::new(File::create(&dest)?);
        io::copy(&mut entry.by_ref().take(size), &mut hw)?;
        let (mut f, hash, written) = hw.finish();
        f.flush()?;
        if written != size || hash != fe.sha256 {
            return Err(ExtractError::HashMismatch(rel).into());
        }
        seen.insert(rel, ());
    }

    for f in &meta.files {
        if !seen.contains_key(&f.path) {
            return Err(ExtractError::MissingFile(f.path.clone()).into());
        }
    }

    // 3. Move into place.
    let staged = tmp.path().join(&meta.root);
    if overwrite && final_path.exists() {
        if final_path.is_dir() {
            fs::remove_dir_all(&final_path)?;
        } else {
            fs::remove_file(&final_path)?;
        }
    }
    fs::rename(&staged, &final_path)?;
    Ok(ExtractReport { root: final_path, files: seen.len(), bytes: n_bytes, meta })
}
```

```rust
    /// Zeroized on drop (spec 10.5).
    pub words: zeroize::Zeroizing<Vec<String>>,
    pub entropy_bits: f64,
}

impl Passphrase {
    pub fn joined(&self) -> zeroize::Zeroizing<String> {
        zeroize::Zeroizing::new(self.words.join(" "))
    }
    pub fn as_secret(&self) -> SecretString {
        SecretString::from(self.words.join(" "))
    }
}

pub fn min_words(list: WordList) -> usize {
    match list {
        WordList::Eff => 6,
        WordList::Bip39 => 10,
    }
}

pub(crate) fn eff_words() -> Vec<&'static str> {
    EFF_RAW.lines().filter_map(|l| l.split('\t').nth(1)).map(str::trim).filter(|w| !w.is_empty()).collect()
}

pub(crate) fn bip39_words() -> Vec<&'static str> {
    BIP39_RAW.lines().map(str::trim).filter(|w| !w.is_empty()).collect()
}

/// Generates `max(count, min_words(list))` words from the OS CSPRNG.
pub fn generate(list: WordList, count: usize) -> Passphrase {
    let words = match list {
        WordList::Eff => eff_words(),
        WordList::Bip39 => bip39_words(),
    };
    let n = count.max(min_words(list));
    let mut rng = rand::rng();
    let chosen: Vec<String> = (0..n).map(|_| words[rng.random_range(0..words.len())].to_string()).collect();
    let entropy_bits = n as f64 * (words.len() as f64).log2();
    Passphrase { words: zeroize::Zeroizing::new(chosen), entropy_bits }
}
```

```rust
use std::collections::BTreeMap;

use crate::{Error, Result};

pub const SCRYPT_DEFAULT_LOG_N: u8 = 18;
pub const SCRYPT_HIGH_LOG_N: u8 = 20;
pub const SCRYPT_MAX_DECRYPT_LOG_N: u8 = 22;

#[derive(Clone)]
pub enum Recipient {
    X25519(age::x25519::Recipient),
    Hybrid(age::tagpq::Recipient),
    Plugin(age::plugin::Recipient),
}

impl Recipient {
    pub fn parse(s: &str) -> Result<Self> {
        let s = s.trim();
        if let Ok(r) = age::x25519::Recipient::from_str(s) {
            return Ok(Self::X25519(r));
        }
        if let Ok(r) = age::tagpq::Recipient::from_str(s) {
            return Ok(Self::Hybrid(r));
        }
        if let Ok(r) = age::plugin::Recipient::from_str(s) {
            return Ok(Self::Plugin(r));
        }
        Err(Error::InvalidRecipient(s.to_string()))
    }

    pub fn kind(&self) -> String {
        match self {
            Self::X25519(_) => "x25519".into(),
            Self::Hybrid(_) => "hybrid-pq".into(),
            Self::Plugin(p) => format!("plugin:{}", p.plugin()),
        }
    }

    pub fn plugin_name(&self) -> Option<String> {
        match self {
            Self::Plugin(p) => Some(p.plugin().to_string()),
            _ => None,
        }
    }

    /// First 16 hex chars of SHA-256 of the recipient string.
    pub fn fingerprint(&self) -> String {
        sha256_hex(self.to_string().as_bytes())[..16].to_string()
    }
}

impl fmt::Display for Recipient {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        match self {
            Self::X25519(r) => write!(f, "{r}"),
            Self::Hybrid(r) => write!(f, "{r}"),
            Self::Plugin(r) => write!(f, "{r}"),
        }
    }
}

pub fn scrypt_recipient(pass: SecretString, log_n: u8) -> age::scrypt::Recipient {
    let mut r = age::scrypt::Recipient::new(pass);
    r.set_work_factor(log_n);
    r
}

    i.set_max_work_factor(SCRYPT_MAX_DECRYPT_LOG_N);
    i

/// Converts parsed recipients into age recipients; plugin recipients are grouped by
/// plugin name and resolved through the plugin binary on PATH.
pub fn to_age_recipients(specs: &[Recipient]) -> Result<Vec<Box<dyn age::Recipient + Send>>> {
    let mut out: Vec<Box<dyn age::Recipient + Send>> = Vec::new();
    let mut plugins: BTreeMap<String, Vec<age::plugin::Recipient>> = BTreeMap::new();
    for s in specs {
        match s {
            Recipient::X25519(r) => out.push(Box::new(r.clone())),
            Recipient::Hybrid(r) => out.push(Box::new(r.clone())),
            Recipient::Plugin(p) => plugins.entry(p.plugin().to_string()).or_default().push(p.clone()),
        }
    }
    for (name, recips) in plugins {
        let plugin = age::plugin::RecipientPluginV1::new(&name, &recips, &[], age::NoCallbacks)
            .map_err(|e| Error::Other(format!("age-plugin-{name}: {e}")))?;
        out.push(Box::new(plugin));
    }
    Ok(out)
}

/// Builds plugin identities from `AGE-PLUGIN-...` lines.
pub fn plugin_identities(lines: &[String]) -> Result<Vec<Box<dyn age::Identity>>> {
    let mut by_plugin: BTreeMap<String, Vec<age::plugin::Identity>> = BTreeMap::new();
    for l in lines {
        let id = age::plugin::Identity::from_str(l.trim()).map_err(|_| Error::InvalidIdentity)?;
        by_plugin.entry(id.plugin().to_string()).or_default().push(id);
    }
    let mut out: Vec<Box<dyn age::Identity>> = Vec::new();
    for (name, ids) in by_plugin {
        let p = age::plugin::IdentityPluginV1::new(&name, &ids, age::NoCallbacks)
            .map_err(|e| Error::Other(format!("age-plugin-{name}: {e}")))?;
        out.push(Box::new(p));
    }
    Ok(out)
}

pub struct CipherWriter<W: Write> {
    inner: StreamWriter<ArmoredWriter<W>>,
}

impl<W: Write> Write for CipherWriter<W> {
    fn write(&mut self, buf: &[u8]) -> std::io::Result<usize> {
        self.inner.write(buf)
    }
    fn flush(&mut self) -> std::io::Result<()> {
        self.inner.flush()
    }
}

impl<W: Write> CipherWriter<W> {
    pub fn finish(self) -> Result<W> {
        let armored = self.inner.finish()?;
        Ok(armored.finish()?)
    }
}

pub fn encrypt_writer<W: Write>(
    out: W,
    recipients: &[Box<dyn age::Recipient + Send>],
    armor: bool,
) -> Result<CipherWriter<W>> {
    let enc = age::Encryptor::with_recipients(recipients.iter().map(|r| r.as_ref() as &dyn age::Recipient))?;
    let format = if armor { Format::AsciiArmor } else { Format::Binary };
    let armored = ArmoredWriter::wrap_output(out, format)?;
    Ok(CipherWriter { inner: enc.wrap_output(armored)? })
}

pub fn decrypt_reader<'a, R: Read>(input: R, identities: &[Box<dyn age::Identity + 'a>]) -> Result<impl Read> {
    let armored = ArmoredReader::new(BufReader::new(input));
    let dec = age::Decryptor::new(armored)?;
    let reader = dec.decrypt(identities.iter().map(|i| i.as_ref()))?;
    Ok(reader)
}
```

```rust
//! Optional Argon2id passphrase stanza (spec 5). Off by default. Files using it do not
//! open in stock age tools; the stanza tag makes them fail cleanly with "no matching keys".

use std::collections::HashSet;

use age::secrecy::{ExposeSecret, SecretString};
use age::{DecryptError, EncryptError};
use age_core::format::{FileKey, Stanza, FILE_KEY_BYTES};
use argon2::{Algorithm, Argon2, Version};
use base64::prelude::{Engine, BASE64_STANDARD_NO_PAD};
use chacha20poly1305::aead::{Aead, KeyInit};
use chacha20poly1305::{ChaCha20Poly1305, Key, Nonce};
use rand::RngCore;
use zeroize::Zeroizing;

pub const TAG: &str = "sealdrop-argon2id";
const SALT_LEN: usize = 16;
const DOMAIN: &[u8] = b"sealdrop-argon2id";

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Params {
    pub t: u32,
    pub m_kib: u32,
    pub p: u32,
}

/// Upper bounds accepted on decrypt (spec 5).
pub const MAX: Params = Params { t: 10, m_kib: 2 * 1024 * 1024, p: 8 };

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Profile {
    /// RFC 9106 first recommendation: t=1, m=2 GiB, p=4.
    Desktop,
    /// RFC 9106 second recommendation: t=3, m=256 MiB, p=4.
    Compat,
}

impl Profile {
    pub fn params(self) -> Params {
        match self {
            Profile::Desktop => Params { t: 1, m_kib: 2 * 1024 * 1024, p: 4 },
            Profile::Compat => Params { t: 3, m_kib: 256 * 1024, p: 4 },
        }
    }
}

fn derive(pass: &SecretString, salt: &[u8], params: Params) -> Result<Zeroizing<[u8; 32]>, String> {
    let p = argon2::Params::new(params.m_kib, params.t, params.p, Some(32)).map_err(|e| e.to_string())?;
    let a = Argon2::new(Algorithm::Argon2id, Version::V0x13, p);
    let mut full_salt = Vec::with_capacity(DOMAIN.len() + salt.len());
    full_salt.extend_from_slice(DOMAIN);
    full_salt.extend_from_slice(salt);
    let mut out = Zeroizing::new([0u8; 32]);
    a.hash_password_into(pass.expose_secret().as_bytes(), &full_salt, out.as_mut())
        .map_err(|e| e.to_string())?;
    Ok(out)
}

pub struct Recipient {
    pass: SecretString,
    params: Params,
}

impl Recipient {
    pub fn new(pass: SecretString, profile: Profile) -> Self {
        Self { pass, params: profile.params() }
    }
    pub fn with_params(pass: SecretString, params: Params) -> Self {
        Self { pass, params }
    }
}

impl age::Recipient for Recipient {
    fn wrap_file_key(&self, file_key: &FileKey) -> Result<(Vec<Stanza>, HashSet<String>), EncryptError> {
        let mut salt = [0u8; SALT_LEN];
        rand::rng().fill_bytes(&mut salt);
        let key = derive(&self.pass, &salt, self.params)
            .map_err(|e| EncryptError::Io(std::io::Error::other(e)))?;
        let aead = ChaCha20Poly1305::new(&Key::from(*key));
        let body = aead
            .encrypt(&Nonce::from([0u8; 12]), file_key.expose_secret().as_slice())
            .map_err(|_| EncryptError::Io(std::io::Error::other("aead")))?;
        let stanza = Stanza {
            tag: TAG.into(),
            args: vec![
                BASE64_STANDARD_NO_PAD.encode(salt),
                self.params.t.to_string(),
                self.params.m_kib.to_string(),
                self.params.p.to_string(),
            ],
            body,
        };
        let mut labels = HashSet::new();
        labels.insert(TAG.to_string());
        Ok((vec![stanza], labels))
    }
}

pub struct Identity {
    pass: SecretString,
}

impl Identity {
    pub fn new(pass: SecretString) -> Self {
        Self { pass }
    }
}

fn log2_ceil(v: u32) -> u8 {
    (32 - v.saturating_sub(1).leading_zeros()) as u8
}

impl age::Identity for Identity {
    fn unwrap_stanza(&self, stanza: &Stanza) -> Option<Result<FileKey, DecryptError>> {
        if stanza.tag != TAG {
            return None;
        }
        if stanza.args.len() != 4 || stanza.body.len() != 32 {
            return Some(Err(DecryptError::InvalidHeader));
        }
        let salt = match BASE64_STANDARD_NO_PAD.decode(&stanza.args[0]) {
            Ok(s) if s.len() == SALT_LEN => s,
            _ => return Some(Err(DecryptError::InvalidHeader)),
        };
        let parse = |s: &str| s.parse::<u32>().ok().filter(|v| *v > 0);
        let (t, m_kib, p) = match (parse(&stanza.args[1]), parse(&stanza.args[2]), parse(&stanza.args[3])) {
            (Some(t), Some(m), Some(p)) => (t, m, p),
            _ => return Some(Err(DecryptError::InvalidHeader)),
        };
        // Argon2 minimums (m >= 8 and m >= 8p) are a header-validity matter, not a
        // passphrase matter: report them as InvalidHeader before any work.
        if m_kib < 8 || m_kib < 8 * p {
            return Some(Err(DecryptError::InvalidHeader));
        }
        if let Err(e) = check_bounds(Params { t, m_kib, p }) {
            return Some(Err(e));
        }
        let key = match derive(&self.pass, &salt, Params { t, m_kib, p }) {
            Ok(k) => k,
            Err(DeriveError::BadParams) => return Some(Err(DecryptError::InvalidHeader)),
            Err(DeriveError::Failed) => return Some(Err(DecryptError::DecryptionFailed)),
        };
        let aead = ChaCha20Poly1305::new(&Key::from(*key));
        match aead.decrypt(&Nonce::from([0u8; 12]), stanza.body.as_slice()) {
            Ok(pt) => {
                let pt = Zeroizing::new(pt); // wiped on every arm below
                if pt.len() != FILE_KEY_BYTES {
                    return Some(Err(DecryptError::DecryptionFailed));
                }
                let mut arr = [0u8; FILE_KEY_BYTES];
                arr.copy_from_slice(&pt);
                let fk = FileKey::new(Box::new(arr));
                arr.zeroize();
                Some(Ok(fk))
            }
            Err(_) => Some(Err(DecryptError::DecryptionFailed)),
        }
    }
}

/// Decrypt bounds (spec 5), unit-tested directly so the 2 GiB boundary needs no derivation.
pub fn check_bounds(p: Params) -> Result<(), DecryptError> {
    if p.t > MAX.t || p.m_kib > MAX.m_kib || p.p > MAX.p {
        return Err(DecryptError::ExcessiveWork { required: log2_ceil(p.m_kib), target: log2_ceil(MAX.m_kib) });
    }
    Ok(())
}

enum DeriveError {
    /// `argon2::Params::new` rejected the parameters (header problem).
    BadParams,
    /// The derivation itself failed (treated like a wrong passphrase).
    Failed,
```

```rust
//! Delivery manifest (spec 4.3) and minisign signatures.

use std::io::Cursor;

use serde::{Deserialize, Serialize};

use crate::{Error, Result};

pub const MANIFEST_FORMAT: &str = "sealdrop-manifest/1";
pub const NOTES: &str = "expires is advisory and is not enforced by any software; release.window_secs is enforced by the named service for the encrypted package only";

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct CiphertextInfo {
    pub file: String,
    pub size: u64,
    pub sha256: String,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct RecipientInfo {
    pub kind: String,
    pub fingerprint: String,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ReleaseInfo {
    pub service: String,
    pub release_id: String,
    pub window_secs: u64,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Manifest {
    pub format: String,
    pub package_id: String,
    pub tool: String,
    pub created: String,
    pub ciphertext: CiphertextInfo,
    pub plaintext_tar_sha256: String,
    pub recipients: Vec<RecipientInfo>,
    pub signer: String,
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub classification: Option<String>,
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub expires: Option<String>,
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub release: Option<ReleaseInfo>,
    pub notes: String,
}

impl Manifest {
    pub fn to_json(&self) -> Result<Vec<u8>> {
        serde_json::to_vec_pretty(self).map_err(|e| Error::Manifest(e.to_string()))
    }
    pub fn from_json(bytes: &[u8]) -> Result<Manifest> {
        if bytes.len() > 1024 * 1024 {
            return Err(Error::Manifest("manifest too large".into()));
        }
        let m: Manifest = serde_json::from_slice(bytes).map_err(|e| Error::Manifest(e.to_string()))?;
        if m.format != MANIFEST_FORMAT {
            return Err(Error::Manifest(format!("unknown manifest format {}", m.format)));
        }
        Ok(m)
    }
}

pub fn sign(bytes: &[u8], sk: &minisign::SecretKey, pk: &minisign::PublicKey, package_id: &str) -> Result<minisign::SignatureBox> {
    let comment = format!("sealdrop manifest {package_id}");
    minisign::sign(Some(pk), sk, Cursor::new(bytes), Some(&comment), None)
        .map_err(|e| Error::Manifest(format!("sign: {e}")))
}

pub fn verify(bytes: &[u8], sig: &minisign::SignatureBox, pk: &minisign::PublicKey) -> Result<()> {
    minisign::verify(pk, sig, Cursor::new(bytes), true, false, false)
        .map_err(|e| Error::Verify(format!("manifest signature invalid: {e}")))
}
```

```rust
fn write_private(path: &Path, contents: &str) -> Result<()> {
    fs::write(path, contents)?;
    #[cfg(unix)]
    {
        use std::os::unix::fs::PermissionsExt;
        fs::set_permissions(path, fs::Permissions::from_mode(0o600))?;
    }
    Ok(())
}

impl KeyStore {
    pub fn default_dir() -> PathBuf {
        dirs::config_dir().unwrap_or_else(|| PathBuf::from(".")).join("sealdrop")
    }
    pub fn open(dir: impl Into<PathBuf>) -> Self {
        Self { dir: dir.into() }
    }
    pub fn dir(&self) -> &Path {
        &self.dir
    }
    fn identity_path(&self) -> PathBuf { self.dir.join("identity.txt") }
    fn sign_key_path(&self) -> PathBuf { self.dir.join("sign.key") }
    fn sign_pub_path(&self) -> PathBuf { self.dir.join("sign.pub") }
    fn trusted_dir(&self) -> PathBuf { self.dir.join("trusted") }
    fn settings_path(&self) -> PathBuf { self.dir.join("settings.json") }

    pub fn exists(&self) -> bool {
        self.identity_path().exists() && self.sign_key_path().exists()
    }

    pub fn generate(&self, force: bool) -> Result<KeyInfo> {
        if self.exists() && !force {
            return Err(Error::KeyStore(format!("identity already exists in {}; use --force to replace", self.dir.display())));
        }
        fs::create_dir_all(&self.dir)?;
        #[cfg(unix)]
        {
            use std::os::unix::fs::PermissionsExt;
            fs::set_permissions(&self.dir, fs::Permissions::from_mode(0o700))?;
        }
        let id = age::x25519::Identity::generate();
        let recipient = id.to_public().to_string();
        let created = chrono::Utc::now().format("%Y-%m-%dT%H:%M:%SZ");
        let body = format!("# created: {created}\n# public key: {recipient}\n{}\n", id.to_string().expose_secret());
        write_private(&self.identity_path(), &body)?;

        let kp = minisign::KeyPair::generate_unencrypted_keypair().map_err(|e| Error::KeyStore(e.to_string()))?;
        let sk_box = kp.sk.to_box(Some("sealdrop signing key")).map_err(|e| Error::KeyStore(e.to_string()))?;
        write_private(&self.sign_key_path(), &sk_box.into_string())?;
        let pk_box = kp.pk.to_box().map_err(|e| Error::KeyStore(e.to_string()))?;
        fs::write(self.sign_pub_path(), pk_box.into_string())?;
        Ok(KeyInfo { recipient, signer: kp.pk.to_base64() })
    }

    fn identity_lines(&self) -> Result<Vec<String>> {
        let text = fs::read_to_string(self.identity_path())
            .map_err(|_| Error::KeyStore("no identity; run `sealdrop keygen`".into()))?;
        Ok(text.lines().map(|l| l.trim().to_string()).filter(|l| !l.is_empty() && !l.starts_with('#')).collect())
    }

        let line = self
            .identity_lines()?
            .into_iter()
            .find(|l| l.starts_with("AGE-SECRET-KEY-1"))
            .ok_or(Error::InvalidIdentity)?;
        age::x25519::Identity::from_str(&line).map_err(|_| Error::InvalidIdentity)
    }

    /// Lines starting with `AGE-PLUGIN-` (hardware identities the user added by hand).
    pub fn plugin_identity_lines(&self) -> Result<Vec<String>> {
        Ok(self.identity_lines()?.into_iter().filter(|l| l.starts_with("AGE-PLUGIN-")).collect())
    }

    pub fn recipient_string(&self) -> Result<String> {
        Ok(self.identity()?.to_public().to_string())
    }

    pub fn signing_key(&self) -> Result<minisign::SecretKey> {
        let s = fs::read_to_string(self.sign_key_path()).map_err(|_| Error::KeyStore("no signing key".into()))?;
        minisign::SecretKeyBox::from_string(&s)
            .and_then(|b| b.into_unencrypted_secret_key())
            .map_err(|e| Error::KeyStore(e.to_string()))
    }

    pub fn signing_public(&self) -> Result<minisign::PublicKey> {
        let s = fs::read_to_string(self.sign_pub_path()).map_err(|_| Error::KeyStore("no signing key".into()))?;
        minisign::PublicKeyBox::from_string(&s)
            .and_then(|b| b.into_public_key())
            .map_err(|e| Error::KeyStore(e.to_string()))
    }

    pub fn signing_public_string(&self) -> Result<String> {
        Ok(self.signing_public()?.to_base64())
    }

    pub fn trusted(&self) -> Result<Vec<(String, minisign::PublicKey)>> {
        let dir = self.trusted_dir();
        if !dir.exists() {
            return Ok(vec![]);
        }
        let mut out = Vec::new();
        for e in fs::read_dir(dir)? {
            let e = e?;
            let name = e.file_name().to_string_lossy().into_owned();
            if let Some(stem) = name.strip_suffix(".pub") {
                let s = fs::read_to_string(e.path())?;
                let pk = minisign::PublicKey::from_base64(s.trim()).map_err(|e| Error::KeyStore(e.to_string()))?;
                out.push((stem.to_string(), pk));
            }
        }
        out.sort_by(|a, b| a.0.cmp(&b.0));
        Ok(out)
    }

    pub fn add_trusted(&self, name: &str, pk_b64: &str) -> Result<()> {

        fs::write(self.trusted_dir().join(format!("{name}.pub")), pk_b64.trim())?;
        Ok(())
    }

        fs::remove_file(self.trusted_dir().join(format!("{name}.pub")))?;

        write_private(&self.settings_path(), &String::from_utf8_lossy(&b))?;
        Ok(())
    }
```

```rust
//! Recipient policy (spec 5.4, 10).

use crate::crypt::Recipient;

pub const ALLOWED_PLUGINS: &[&str] = &["yubikey", "fido2prf", "se", "tpm"];

#[derive(Debug, Clone, PartialEq, Eq, thiserror::Error)]
pub enum PolicyError {
    #[error("no recipients given")]
    NoRecipients,
    #[error("a passphrase cannot be combined with other recipients")]
    PassphraseMustBeAlone,
    #[error("hardware-only recipients need a recovery recipient (or --allow-unrecoverable)")]
    HardwareOnlyNeedsRecovery,
    #[error("plugin `{0}` is not on the allow-list")]
    PluginNotAllowed(String),
}

pub fn plugin_allowed(name: &str) -> bool {
    ALLOWED_PLUGINS.contains(&name)
}

pub fn check_recipients(recipients: &[Recipient], passphrase_mode: bool, allow_unrecoverable: bool) -> Result<(), PolicyError> {
    if passphrase_mode {
        return if recipients.is_empty() { Ok(()) } else { Err(PolicyError::PassphraseMustBeAlone) };
    }
    if recipients.is_empty() {
        return Err(PolicyError::NoRecipients);
    }
    for r in recipients {
        if let Some(name) = r.plugin_name() {
            if !plugin_allowed(&name) {
                return Err(PolicyError::PluginNotAllowed(name));
            }
        }
    }
    let all_hardware = recipients.iter().all(|r| r.plugin_name().is_some());
    if all_hardware && !allow_unrecoverable {
        return Err(PolicyError::HardwareOnlyNeedsRecovery);
    }
    Ok(())
}
```

```rust
//! Bounded scan of an age header (spec 10.3) to learn which stanza types are present
//! before any decryption or network call.

use std::fs::File;
use std::io::Read;
use std::path::Path;

use base64::prelude::{Engine, BASE64_STANDARD_NO_PAD};

use crate::{Error, Result};

pub const HEADER_MAX: usize = 64 * 1024;

#[derive(Debug, Clone)]
pub struct ReleaseArgs {
    pub release_id: String,
    pub service: String,
    pub nonce_b64: String,
    pub unlock_token_b64: String,
}

#[derive(Debug, Clone)]
pub struct Probe {
    pub armored: bool,
    pub tags: Vec<String>,
    pub needs_passphrase: bool,
    pub release: Option<ReleaseArgs>,
}

pub fn probe(path: &Path) -> Result<Probe> {
    let mut buf = Vec::with_capacity(HEADER_MAX);
    File::open(path)?.take(HEADER_MAX as u64 + 1).read_to_end(&mut buf)?;
    probe_bytes(&buf)
}

pub fn probe_bytes(buf: &[u8]) -> Result<Probe> {
    let armored = buf.starts_with(b"-----BEGIN AGE ENCRYPTED FILE-----");
    let text: Vec<u8> = if armored {
        let s = String::from_utf8_lossy(buf);
        let body: String = s
            .lines()
            .skip(1)
            .take_while(|l| !l.starts_with("-----END"))
            .map(str::trim)
            .collect();
        let decoded = base64::prelude::BASE64_STANDARD
            .decode(body.as_bytes())
            .or_else(|_| BASE64_STANDARD_NO_PAD.decode(body.as_bytes()))
            .map_err(|_| Error::Other("armor decode failed".into()))?;
        decoded
    } else {
        buf.to_vec()
    };
    let end = find(&text, b"\n---").ok_or_else(|| Error::Other("age header not found within 64 KiB".into()))?;
    if end > HEADER_MAX {
        return Err(Error::Other("age header too large".into()));
    }
    let header = String::from_utf8_lossy(&text[..end]);
    if !header.starts_with("age-encryption.org/v1") {
        return Err(Error::Other("not an age file".into()));
    }
    let mut tags = Vec::new();
    let mut release = None;
    for line in header.lines() {
        if let Some(rest) = line.strip_prefix("-> ") {
            let parts: Vec<&str> = rest.split(' ').collect();
            let tag = parts[0].to_string();
            if tag == crate::release::TAG && parts.len() == 5 {
                let service = BASE64_STANDARD_NO_PAD
                    .decode(parts[2])
                    .ok()
                    .and_then(|b| String::from_utf8(b).ok())
                    .ok_or_else(|| Error::Other("bad release stanza".into()))?;
                release = Some(ReleaseArgs {
                    release_id: parts[1].to_string(),
                    service,
                    nonce_b64: parts[3].to_string(),
                    unlock_token_b64: parts[4].to_string(),
                });
            }
            tags.push(tag);
        }
    }
    let needs_passphrase = tags.iter().any(|t| t == "scrypt" || t == crate::argon2id::TAG);
    Ok(Probe { armored, tags, needs_passphrase, release })
}

fn find(hay: &[u8], needle: &[u8]) -> Option<usize> {
    hay.windows(needle.len()).position(|w| w == needle)
```

```rust
//! Timed release (spec 5.5): nested wrap of inner recipient stanzas under a service-held
//! key, plus the HTTP client for deposit, unlock and receipts.

use std::cell::RefCell;
use std::collections::HashSet;

use age::{DecryptError, EncryptError};
use age_core::format::{FileKey, Stanza};
use base64::prelude::{Engine, BASE64_STANDARD_NO_PAD};
use chacha20poly1305::aead::{Aead, KeyInit};
use chacha20poly1305::{ChaCha20Poly1305, Key, Nonce};
use rand::RngCore;
use serde::{Deserialize, Serialize};
use zeroize::Zeroizing;

use crate::hashing::sha256_hex;
use crate::{Error, Result};

pub const TAG: &str = "sealdrop-release";

#[derive(Serialize, Deserialize)]
struct InnerStanza {
    tag: String,
    args: Vec<String>,
    body: String,
}

#[derive(Serialize, Deserialize)]
struct InnerStanzas {
    stanzas: Vec<InnerStanza>,
}

pub struct Deposit {
    pub release_id: String,
    pub k_release: Zeroizing<[u8; 32]>,
    pub unlock_token: Zeroizing<[u8; 32]>,
    pub window_secs: u64,
}

impl Deposit {
    pub fn new(window_secs: u64) -> Self {
        let mut k = Zeroizing::new([0u8; 32]);
        let mut t = Zeroizing::new([0u8; 32]);
        rand::rng().fill_bytes(k.as_mut());
        rand::rng().fill_bytes(t.as_mut());
        Self { release_id: uuid::Uuid::new_v4().to_string(), k_release: k, unlock_token: t, window_secs }
    }
    pub fn unlock_token_b64(&self) -> String {
        BASE64_STANDARD_NO_PAD.encode(*self.unlock_token)
    }
    pub fn unlock_token_hash(&self) -> String {
        sha256_hex(self.unlock_token.as_ref())
    }
}

pub struct Recipient {
    inner: Vec<Box<dyn age::Recipient + Send>>,
    k_release: Zeroizing<[u8; 32]>,
    release_id: String,
    service: String,
    unlock_token_b64: String,
}

impl Recipient {
    pub fn new(inner: Vec<Box<dyn age::Recipient + Send>>, deposit: &Deposit, service: &str) -> Self {
        Self {
            inner,
            k_release: deposit.k_release.clone(),
            release_id: deposit.release_id.clone(),
            service: service.trim_end_matches('/').to_string(),
            unlock_token_b64: deposit.unlock_token_b64(),
        }
    }
}

impl age::Recipient for Recipient {
    fn wrap_file_key(&self, file_key: &FileKey) -> std::result::Result<(Vec<Stanza>, HashSet<String>), EncryptError> {
        let mut inner = Vec::new();
        for r in &self.inner {
            let (stanzas, _labels) = r.wrap_file_key(file_key)?;
            for s in stanzas {
                inner.push(InnerStanza { tag: s.tag, args: s.args, body: BASE64_STANDARD_NO_PAD.encode(s.body) });
            }
        }
        if inner.is_empty() {
            return Err(EncryptError::MissingRecipients);
        }
        let json = serde_json::to_vec(&InnerStanzas { stanzas: inner })
            .map_err(|e| EncryptError::Io(std::io::Error::other(e)))?;
        let mut nonce = [0u8; 12];
        rand::rng().fill_bytes(&mut nonce);
        let aead = ChaCha20Poly1305::new(&Key::from(*self.k_release));
        let body = aead
            .encrypt(&Nonce::from(nonce), json.as_slice())
            .map_err(|_| EncryptError::Io(std::io::Error::other("aead")))?;
        let stanza = Stanza {
            tag: TAG.into(),
            args: vec![
                self.release_id.clone(),
                BASE64_STANDARD_NO_PAD.encode(self.service.as_bytes()),
                BASE64_STANDARD_NO_PAD.encode(nonce),
                self.unlock_token_b64.clone(),
            ],
            body,
        };
        let mut labels = HashSet::new();
        labels.insert(TAG.to_string());
        Ok((vec![stanza], labels))
    }
}

#[derive(Clone, Serialize, Deserialize)]
pub struct Unlock {
    pub k_release: Zeroizing<[u8; 32]>,
    pub first_unlock: String,
    pub expires_at: String,
}

pub trait ReleaseFetch {
    fn unlock(&self, service: &str, release_id: &str, unlock_token_b64: &str) -> Result<Unlock>;
}

pub struct Identity {
    inner: Vec<Box<dyn age::Identity>>,
    fetch: Box<dyn ReleaseFetch>,
    last: RefCell<Option<Unlock>>,
}

impl Identity {
    pub fn new(inner: Vec<Box<dyn age::Identity>>, fetch: Box<dyn ReleaseFetch>) -> Self {
        Self { inner, fetch, last: RefCell::new(None) }
    }
    pub fn last_unlock(&self) -> Option<Unlock> {
        self.last.borrow().clone()
    }
}

impl age::Identity for Identity {
    fn unwrap_stanza(&self, stanza: &Stanza) -> Option<std::result::Result<FileKey, DecryptError>> {
        if stanza.tag != TAG {
            // Not timed release: delegate to inner identities directly.
            return self.inner.iter().find_map(|i| i.unwrap_stanza(stanza));
        }
        if stanza.args.len() != 4 {
            return Some(Err(DecryptError::InvalidHeader));
        }
        let service = match BASE64_STANDARD_NO_PAD.decode(&stanza.args[1]).ok().and_then(|b| String::from_utf8(b).ok()) {
            Some(s) => s,
            None => return Some(Err(DecryptError::InvalidHeader)),
        };
        let nonce = match BASE64_STANDARD_NO_PAD.decode(&stanza.args[2]) {
            Ok(n) if n.len() == 12 => n,
            _ => return Some(Err(DecryptError::InvalidHeader)),
        };
        let unlock = match self.fetch.unlock(&service, &stanza.args[0], &stanza.args[3]) {
            Ok(u) => u,
            Err(e) => return Some(Err(DecryptError::Io(std::io::Error::other(e.to_string())))),
        };
        let aead = ChaCha20Poly1305::new(&Key::from(*unlock.k_release));
        let mut n = [0u8; 12];
        n.copy_from_slice(&nonce);
        let json = match aead.decrypt(&Nonce::from(n), stanza.body.as_slice()) {
            Ok(j) => j,
            Err(_) => return Some(Err(DecryptError::DecryptionFailed)),
        };
        let inner: InnerStanzas = match serde_json::from_slice(&json) {
            Ok(i) => i,
            Err(_) => return Some(Err(DecryptError::InvalidHeader)),
        };
        if inner.stanzas.len() > 64 {
            return Some(Err(DecryptError::InvalidHeader));
        }
        let stanzas: Vec<Stanza> = inner
            .stanzas
            .into_iter()
            .filter_map(|s| {
                BASE64_STANDARD_NO_PAD.decode(s.body).ok().map(|body| Stanza { tag: s.tag, args: s.args, body })
            })
            .collect();
        *self.last.borrow_mut() = Some(unlock);
        match self.inner.iter().find_map(|i| i.unwrap_stanzas(&stanzas)) {
            Some(r) => Some(r),
            None => Some(Err(DecryptError::NoMatchingKeys)),
        }
    }
}

#[derive(Serialize)]
struct DepositBody<'a> {
    k_release: String,
    window_secs: u64,
    unlock_token_hash: String,
    package_sha256: &'a str,
}

#[derive(Serialize)]
struct UnlockBody<'a> {
    unlock_token: &'a str,
}

#[derive(Deserialize)]
struct UnlockResponse {
    k_release: String,
    first_unlock: String,
    expires_at: String,
}

pub struct HttpFetch;

impl ReleaseFetch for HttpFetch {
    fn unlock(&self, service: &str, release_id: &str, unlock_token_b64: &str) -> Result<Unlock> {
        let url = format!("{}/v1/releases/{release_id}/unlock", service.trim_end_matches('/'));
        let res = ureq::post(&url).send_json(UnlockBody { unlock_token: unlock_token_b64 });
        let mut res = match res {
            Ok(r) => r,
            Err(ureq::Error::StatusCode(410)) => return Err(Error::ReleaseExpired),
            Err(ureq::Error::StatusCode(403)) => return Err(Error::Release("unlock token rejected".into())),
            Err(ureq::Error::StatusCode(404)) => return Err(Error::Release("release not found at service".into())),
            Err(e) => return Err(Error::Release(e.to_string())),
        };
        let body: UnlockResponse = res.body_mut().read_json().map_err(|e| Error::Release(e.to_string()))?;
        let raw = BASE64_STANDARD_NO_PAD.decode(body.k_release).map_err(|_| Error::Release("bad key".into()))?;
        if raw.len() != 32 {
            return Err(Error::Release("bad key length".into()));
        }
        let mut k = Zeroizing::new([0u8; 32]);
        k.copy_from_slice(&raw);
        Ok(Unlock { k_release: k, first_unlock: body.first_unlock, expires_at: body.expires_at })
    }
}

pub fn deposit(service: &str, token: &str, d: &Deposit, package_sha256: &str) -> Result<()> {
    let url = format!("{}/v1/releases/{}", service.trim_end_matches('/'), d.release_id);
    ureq::put(&url)
        .header("Authorization", &format!("Bearer {token}"))
        .send_json(DepositBody {
            k_release: BASE64_STANDARD_NO_PAD.encode(*d.k_release),
            window_secs: d.window_secs,
            unlock_token_hash: d.unlock_token_hash(),
            package_sha256,
        })
        .map_err(|e| Error::Release(format!("deposit failed: {e}")))?;
    Ok(())
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
pub struct Receipt {
    pub release_id: String,
    pub package_sha256: String,
    pub first_unlock: Option<String>,
    pub expires_at: Option<String>,
    pub unlock_count: u64,
    pub service_key: String,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct SignedReceipt {
    /// Canonical JSON bytes that were signed (kept verbatim).
    pub receipt_json: String,
    /// minisign signature box text.
    pub signature: String,
}

pub fn sign_receipt(r: &Receipt, sk: &minisign::SecretKey, pk: &minisign::PublicKey) -> Result<SignedReceipt> {
    let receipt_json = serde_json::to_string_pretty(r).map_err(|e| Error::Release(e.to_string()))?;
    let sig = minisign::sign(Some(pk), sk, std::io::Cursor::new(receipt_json.as_bytes()), Some(&format!("sealdrop receipt {}", r.release_id)), None)
        .map_err(|e| Error::Release(e.to_string()))?;
    Ok(SignedReceipt { receipt_json, signature: sig.into_string() })
}

pub fn verify_receipt(s: &SignedReceipt, expected_service_key: Option<&str>) -> Result<Receipt> {
    let r: Receipt = serde_json::from_str(&s.receipt_json).map_err(|e| Error::Verify(e.to_string()))?;
    if let Some(exp) = expected_service_key {
        if exp != r.service_key {
            return Err(Error::Verify("receipt signed by a different service key".into()));
        }
    }
    let pk = minisign::PublicKey::from_base64(&r.service_key).map_err(|e| Error::Verify(e.to_string()))?;
    let sig = minisign::SignatureBox::from_string(&s.signature).map_err(|e| Error::Verify(e.to_string()))?;
    minisign::verify(&pk, &sig, std::io::Cursor::new(s.receipt_json.as_bytes()), true, false, false)
        .map_err(|e| Error::Verify(format!("receipt signature invalid: {e}")))?;
    Ok(r)
}

pub fn fetch_receipt(service: &str, token: &str, release_id: &str) -> Result<SignedReceipt> {
    let url = format!("{}/v1/releases/{release_id}/receipt", service.trim_end_matches('/'));
    let mut res = ureq::get(&url)
        .header("Authorization", &format!("Bearer {token}"))
        .call()
        .map_err(|e| Error::Release(format!("receipt fetch failed: {e}")))?;
    res.body_mut().read_json().map_err(|e| Error::Release(e.to_string()))
}
```

```rust
/// `<name>.sealdrop.age` -> (`<name>.manifest.json`, `<name>.manifest.json.minisig`).
pub fn bundle_paths(package: &Path) -> (PathBuf, PathBuf) {
    let file = package.file_name().map(|s| s.to_string_lossy().into_owned()).unwrap_or_default();
    let stem = file.strip_suffix(".sealdrop.age").unwrap_or(&file).to_string();
    let dir = package.parent().map(Path::to_path_buf).unwrap_or_default();
    let m = dir.join(format!("{stem}.manifest.json"));

pub fn seal(store: &KeyStore, req: SealRequest, progress: &dyn Progress) -> Result<SealResult> {
    let passphrase_mode = matches!(req.mode, Mode::Passphrase { .. });
    let mut specs: Vec<Recipient> = match &req.mode {
        Mode::Recipients(r) => r.clone(),
        Mode::Passphrase { .. } => vec![],
    };
    if req.include_self && !passphrase_mode && req.release.is_none() {
        let me = Recipient::parse(&store.recipient_string()?)?;
        if !specs.iter().any(|r| r.to_string() == me.to_string()) {
            specs.push(me);
        }
    }
    policy::check_recipients(&specs, passphrase_mode, req.allow_unrecoverable)?;

    // Inner recipients.
    let mut passphrase: Option<Passphrase> = None;
    let inner: Vec<Box<dyn age::Recipient + Send>> = match &req.mode {
        Mode::Recipients(_) => crypt::to_age_recipients(&specs)?,
        Mode::Passphrase { list, words, kdf } => {
            let p = generate(*list, *words);
            let secret: SecretString = p.as_secret();
            passphrase = Some(p);
            match kdf {
                Kdf::Scrypt { log_n } => vec![Box::new(crypt::scrypt_recipient(secret, *log_n)?)],
                Kdf::Argon2id(profile) => vec![Box::new(crate::argon2id::Recipient::new(secret, *profile))],
            }
        }
    };

    // Optional timed-release wrap.
    let mut deposit: Option<Deposit> = None;
    let recipients: Vec<Box<dyn age::Recipient + Send>> = if let Some(rc) = &req.release {
        if rc.window_secs == 0 {
            return Err(Error::Other("release window must be at least 1 second".into()));
        }
        let d = Deposit::new(rc.window_secs);
        let r = release::Recipient::new(inner, &d, &rc.service);
        deposit = Some(d);
        vec![Box::new(r)]
    } else {
        inner
    };

    // Paths.
    std::fs::create_dir_all(&req.out_dir)?;
    let name = req.input.file_name().ok_or_else(|| Error::Other("input has no name".into()))?.to_string_lossy().into_owned();
    let package = req.out_dir.join(format!("{name}.sealdrop.age"));
    if package.exists() {
        return Err(Error::Exists(package));
    }
    let (manifest_path, sig_path) = bundle_paths(&package);

    // Pack through the encryptor; `pack` hands the writer back so we can finish it.
    progress.on(ProgressEvent::Packing { path: req.input.display().to_string() });
    let file = BufWriter::new(File::create(&package)?);
    let writer = crypt::encrypt_writer(file, &recipients, req.armor)?;
    let pack_report = match pack(&req.input, writer) {
        Ok((report, w)) => {
            let buf = w.finish()?;
            buf.into_inner().map_err(|e| Error::Io(e.into_error()))?;
            report
        }
        Err(e) => {
            let _ = std::fs::remove_file(&package);
            return Err(e);
        }
    };
    let (ct_sha, ct_size) = crate::hashing::sha256_file(&package)?;
    progress.on(ProgressEvent::Encrypted { bytes: ct_size });

    // Manifest.
    let recipients_info: Vec<RecipientInfo> = if passphrase_mode {
        let kind = match &req.mode {
            Mode::Passphrase { kdf: Kdf::Scrypt { .. }, .. } => "scrypt",
            _ => "argon2id",
        };
        vec![RecipientInfo { kind: kind.into(), fingerprint: String::new() }]
    } else {
        specs.iter().map(|r| RecipientInfo { kind: r.kind(), fingerprint: r.fingerprint() }).collect()
    };
    let package_id = uuid::Uuid::new_v4().to_string();
    let doc = Manifest {
        format: MANIFEST_FORMAT.into(),
        package_id: package_id.clone(),
        tool: TOOL.into(),
        created: chrono::Utc::now().format("%Y-%m-%dT%H:%M:%SZ").to_string(),
        ciphertext: CiphertextInfo { file: format!("{name}.sealdrop.age"), size: ct_size, sha256: ct_sha.clone() },
        plaintext_tar_sha256: pack_report.tar_sha256.clone(),
        recipients: recipients_info,
        signer: store.signing_public_string()?,
        classification: req.classification.clone(),
        expires: req.expires.clone(),
        release: deposit.as_ref().zip(req.release.as_ref()).map(|(d, rc)| ReleaseInfo {
            service: rc.service.trim_end_matches('/').to_string(),
            release_id: d.release_id.clone(),
            window_secs: d.window_secs,
        }),
        notes: NOTES.into(),
    };
    let bytes = doc.to_json()?;
    let sig = manifest::sign(&bytes, &store.signing_key()?, &store.signing_public()?, &package_id)?;
    std::fs::write(&manifest_path, &bytes)?;
    std::fs::write(&sig_path, sig.into_string())?;

    // Deposit last: if it fails, remove the bundle so nothing unopenable is left behind.
    if let (Some(d), Some(rc)) = (&deposit, &req.release) {
        progress.on(ProgressEvent::Contacting { service: rc.service.clone() });
        let r = if rc.service.starts_with("memory://") {
            test_support::remember(&d.k_release);
            Ok(())
        } else {
            release::deposit(&rc.service, &rc.token, d, &ct_sha)
        };
        if let Err(e) = r {
            let _ = std::fs::remove_file(&package);
            let _ = std::fs::remove_file(&manifest_path);
            let _ = std::fs::remove_file(&sig_path);
            return Err(e);
        }
    }
    progress.on(ProgressEvent::Done);
    Ok(SealResult { package, manifest: manifest_path, signature: sig_path, manifest_doc: doc, passphrase, pack: pack_report })
}
```

```rust
//! Verify and open (spec 6, 7, 8): verify manifest and ciphertext hash before decrypting.

use std::fs::File;
use std::io::BufReader;
use std::path::{Path, PathBuf};

use age::secrecy::SecretString;

use crate::crypt;
use crate::extract::{extract, ExtractReport, Limits};
use crate::keys::KeyStore;
use crate::manifest::{self, Manifest};
use crate::probe::probe;
use crate::progress::{Progress, ProgressEvent};
use crate::release::{self, ReleaseFetch, Unlock};
use crate::seal::bundle_paths;
use crate::{Error, Result};

pub struct VerifyReport {
    pub manifest: Manifest,
    pub signer: String,
    pub trusted_as: Option<String>,
    pub ciphertext_ok: bool,
}

fn resolve_signer(store: &KeyStore, manifest_signer: &str, explicit: Option<&str>) -> Result<(minisign::PublicKey, Option<String>)> {
    if let Some(s) = explicit {
        if s != manifest_signer {
            return Err(Error::Verify(format!("manifest signer {manifest_signer} does not match --signer")));
        }
        return Ok((minisign::PublicKey::from_base64(s).map_err(|e| Error::Verify(e.to_string()))?, None));
    }
    if let Ok(own) = store.signing_public_string() {
        if own == manifest_signer {
            return Ok((store.signing_public()?, Some("self".into())));
        }
    }
    for (name, pk) in store.trusted()? {
        if pk.to_base64() == manifest_signer {
            return Ok((pk, Some(name)));
        }
    }
    Err(Error::Verify(format!("signer {manifest_signer} is not trusted; add it with `sealdrop trust add <name> {manifest_signer}` or pass --signer")))
}

pub fn verify(store: &KeyStore, package: &Path, signer: Option<&str>) -> Result<VerifyReport> {
    let (mpath, spath) = bundle_paths(package);
    let bytes = std::fs::read(&mpath).map_err(|_| Error::Verify(format!("manifest not found: {}", mpath.display())))?;
    let sig_text = std::fs::read_to_string(&spath).map_err(|_| Error::Verify(format!("signature not found: {}", spath.display())))?;
    let doc = Manifest::from_json(&bytes)?;
    let (pk, trusted_as) = resolve_signer(store, &doc.signer, signer)?;
    let sig = minisign::SignatureBox::from_string(&sig_text).map_err(|e| Error::Verify(e.to_string()))?;
    manifest::verify(&bytes, &sig, &pk)?;
    let (sha, size) = crate::hashing::sha256_file(package)?;
    if sha != doc.ciphertext.sha256 || size != doc.ciphertext.size {
        return Err(Error::Verify("ciphertext hash does not match the signed manifest".into()));
    }
    Ok(VerifyReport { signer: doc.signer.clone(), manifest: doc, trusted_as, ciphertext_ok: true })
}

pub struct OpenRequest {
    pub package: PathBuf,
    pub out_dir: PathBuf,
    pub signer: Option<String>,
    pub skip_verify: bool,
    pub overwrite: bool,
    pub passphrase: Option<SecretString>,
    pub limits: Limits,
}

pub struct OpenReport {
    pub verify: Option<VerifyReport>,
    pub extract: ExtractReport,
    pub release: Option<Unlock>,
}

pub fn open(store: &KeyStore, req: OpenRequest, fetch: Box<dyn ReleaseFetch>, progress: &dyn Progress) -> Result<OpenReport> {
    let verify_report = if req.skip_verify {
        None
    } else {
        progress.on(ProgressEvent::Verifying);
        Some(verify(store, &req.package, req.signer.as_deref())?)
    };
    let p = probe(&req.package)?;
    if p.needs_passphrase && req.passphrase.is_none() {
        return Err(Error::Other("this package needs a passphrase".into()));
    }

    let mut inner: Vec<Box<dyn age::Identity>> = Vec::new();
    if let Ok(id) = store.identity() {
        inner.push(Box::new(id));
    }
    if let Ok(lines) = store.plugin_identity_lines() {
        if !lines.is_empty() {
            inner.extend(crypt::plugin_identities(&lines)?);
        }
    }
    if let Some(pass) = &req.passphrase {
        inner.push(Box::new(crypt::scrypt_identity(pass.clone())));
        inner.push(Box::new(crate::argon2id::Identity::new(pass.clone())));
    }
    if inner.is_empty() {
        return Err(Error::KeyStore("no identity available; run `sealdrop keygen` or provide a passphrase".into()));
    }
    if let Some(args) = &p.release {
        progress.on(ProgressEvent::Contacting { service: args.service.clone() });
    }
    let wrapper = release::Identity::new(inner, fetch);
    let file = BufReader::new(File::open(&req.package)?);
    let ids: Vec<Box<dyn age::Identity + '_>> = vec![Box::new(IdentityRef(&wrapper))];
    let reader = crypt::decrypt_reader(file, &ids)?;
    progress.on(ProgressEvent::Extracting { path: req.out_dir.display().to_string() });
    let extract_report = extract(reader, &req.out_dir, &req.limits, req.overwrite)?;
    progress.on(ProgressEvent::Done);
    Ok(OpenReport { verify: verify_report, extract: extract_report, release: wrapper.last_unlock() })
}

/// Borrow the wrapper as an identity without moving it, so `last_unlock()` stays readable.
struct IdentityRef<'a>(&'a release::Identity);
impl age::Identity for IdentityRef<'_> {
    fn unwrap_stanza(&self, stanza: &age_core::format::Stanza) -> Option<std::result::Result<age_core::format::FileKey, age::DecryptError>> {
        age::Identity::unwrap_stanza(self.0, stanza)
    }
}
```

```rust
use std::collections::HashMap;

use std::str::FromStr;

use age::secrecy::SecretString;

struct Vector {
    name: String,
    expect: String,
    payload: Option<String>,
    identities: Vec<String>,
    passphrases: Vec<String>,
    compressed: bool,
    body: Vec<u8>,
}

fn load(path: &PathBuf) -> Vector {
    let raw = std::fs::read(path).unwrap();
    let split = raw.windows(2).position(|w| w == b"\n\n").expect("header separator");
    let header = String::from_utf8_lossy(&raw[..split]).into_owned();
    let mut body = raw[split + 2..].to_vec();
    let mut kv: HashMap<String, Vec<String>> = HashMap::new();
    for line in header.lines() {
        if let Some((k, v)) = line.split_once(": ") {
            kv.entry(k.to_string()).or_default().push(v.to_string());
        }
    }
    let compressed = kv.get("compressed").map(|v| v[0] == "zlib").unwrap_or(false);
    if compressed {
        let mut d = flate2::read::ZlibDecoder::new(&body[..]);
        let mut out = Vec::new();
        d.read_to_end(&mut out).unwrap();
        body = out;
    }
    Vector {
        name: path.file_name().unwrap().to_string_lossy().into_owned(),
        expect: kv.get("expect").map(|v| v[0].clone()).unwrap_or_default(),
        payload: kv.get("payload").map(|v| v[0].clone()),
        identities: kv.get("identity").cloned().unwrap_or_default(),
        passphrases: kv.get("passphrase").cloned().unwrap_or_default(),
        compressed,
        body,
    }
}

            continue;
        }
        let mut ids: Vec<Box<dyn age::Identity>> = Vec::new();
        for i in &v.identities {
            if let Ok(id) = age::x25519::Identity::from_str(i) {
                ids.push(Box::new(id));
            } else if let Ok(id) = age::tagpq::Identity::from_str(i) {
                ids.push(Box::new(id));
            }
        }
        for p in &v.passphrases {
            ids.push(Box::new(scrypt_identity(SecretString::from(p.clone()))));
        }
        let mut hasher = Sha256::new();
        let result: Result<(), String> = (|| {
            let mut r = decrypt_reader(&v.body[..], &ids).map_err(|e| format!("setup: {e}"))?;
            let mut buf = vec![0u8; 1 << 16];
            loop {
                match r.read(&mut buf) {
                    Ok(0) => break,
                    Ok(n) => hasher.update(&buf[..n]),
                    Err(e) => return Err(format!("payload: {e}")),
                }
            }
            Ok(())
        })();
        let got = hex::encode(hasher.finalize());
        let ok = match v.expect.as_str() {
            "success" => result.is_ok() && Some(&got) == v.payload.as_ref(),
            "payload failure" => result.as_ref().map_err(|e| e.starts_with("payload")).err() == Some(true)
                && v.payload.as_ref().map(|p| p == &got).unwrap_or(true),
            "no match" | "HMAC failure" | "header failure" | "armor failure" => result.as_ref().map_err(|e| e.starts_with("setup")).err() == Some(true),
            other => panic!("unknown expect {other}"),
        };
        if !ok {
            failures.push(format!("{} expect={} got={:?} compressed={}", v.name, v.expect, result, v.compressed));
        }
    }
```

```rust
//! sealdrop CLI (spec 8).

mod commands;

use std::path::PathBuf;
use std::process::ExitCode;

use clap::{Parser, Subcommand};
use sealdrop_core::keys::KeyStore;
use sealdrop_core::Error;

#[derive(Parser)]
#[command(name = "sealdrop", version, about = "Send sensitive files with standard encryption, a signed delivery record, and optional timed release.")]
struct Cli {
    #[command(subcommand)]
    cmd: Cmd,
}

#[derive(Subcommand)]
enum Cmd {
    /// Create your identity (age key pair + minisign signing key)
    Keygen { #[arg(long)] force: bool },
    /// Print your public recipient string and signer key
    Recipient,
    /// Encrypt a file or folder to recipients or a generated passphrase
    Seal(commands::seal::Args),
    /// Check the signed manifest and ciphertext hash without decrypting
    Verify(commands::verify::Args),
    /// Verify, decrypt and safely extract a package
    Open(commands::open::Args),
    /// Fetch or verify timed-release receipts
    Receipt { #[command(subcommand)] cmd: commands::receipt::Cmd },
    /// Manage trusted signers
    Trust { #[command(subcommand)] cmd: commands::trust::Cmd },
}

pub(crate) fn store() -> KeyStore {
    match std::env::var_os("SEALDROP_HOME") {
        Some(p) => KeyStore::open(PathBuf::from(p)),
        None => KeyStore::open(KeyStore::default_dir()),
    }
}

pub(crate) fn exit_code_for(e: &anyhow::Error) -> u8 {
    match e.downcast_ref::<Error>() {
        Some(Error::Verify(_)) | Some(Error::ReleaseExpired) => 2,
        Some(Error::Policy(_)) => 3,
        _ => 1,
    }
}

fn main() -> ExitCode {
    let cli = Cli::parse();
    let r = match cli.cmd {
        Cmd::Keygen { force } => commands::keygen::run(force),
        Cmd::Recipient => commands::recipient::run(),
        Cmd::Seal(a) => commands::seal::run(a),
        Cmd::Verify(a) => commands::verify::run(a),
        Cmd::Open(a) => commands::open::run(a),
        Cmd::Receipt { cmd } => commands::receipt::run(cmd),
        Cmd::Trust { cmd } => commands::trust::run(cmd),
    };
    match r {
        Ok(()) => ExitCode::SUCCESS,
        Err(e) => {
            eprintln!("error: {e:#}");
            ExitCode::from(exit_code_for(&e))
        }
    }
}
```

```rust
/// Parses `90s`, `10m`, `6h`, `3d` into seconds.
pub fn parse_window(s: &str) -> anyhow::Result<u64> {
    let s = s.trim();
    let (num, unit) = s.split_at(s.len().saturating_sub(1));
    let n: u64 = num.parse().map_err(|_| anyhow::anyhow!("invalid window `{s}`; use e.g. 90s, 10m, 6h, 3d"))?;
    let mult = match unit {
        "s" => 1,
        "m" => 60,
        "h" => 3600,
        "d" => 86_400,
        _ => anyhow::bail!("invalid window unit in `{s}`; use s, m, h or d"),
    };
    let secs = n.checked_mul(mult).ok_or_else(|| anyhow::anyhow!("window too large"))?;
    anyhow::ensure!(secs >= 1, "window must be at least 1 second");
    Ok(secs)
}
```

```rust
use std::path::PathBuf;

use clap::{Args as ClapArgs, ValueEnum};
use sealdrop_core::argon2id::Profile;
use sealdrop_core::crypt::{Recipient, SCRYPT_DEFAULT_LOG_N, SCRYPT_HIGH_LOG_N};
use sealdrop_core::passphrase::WordList;
use sealdrop_core::seal::{seal, Kdf, Mode, ReleaseConfig, SealRequest};

#[derive(Clone, Copy, ValueEnum)]
pub enum Words { Eff, Bip39 }

#[derive(Clone, Copy, ValueEnum)]
pub enum KdfProfile { Default, High, /// fast parameters for tests only
    Test }

#[derive(ClapArgs)]
pub struct Args {
    /// File or folder to seal
    pub input: PathBuf,
    /// Recipient (age1..., age1pq..., or age1<plugin>1...). Repeatable.
    #[arg(short = 'r', long = "recipient")]
    pub recipients: Vec<String>,
    /// Generate a passphrase instead of using recipients
    #[arg(long)]
    pub passphrase: bool,
    #[arg(long, value_enum, default_value = "eff")]
    pub words: Words,
    #[arg(long, default_value_t = 0, help = "word count (minimum 6 EFF / 10 BIP-39)")]
    pub word_count: usize,
    /// Use the non-standard Argon2id stanza (files will not open in stock age)
    #[arg(long)]
    pub argon2id: bool,
    #[arg(long, value_enum, default_value = "default")]
    pub kdf_profile: KdfProfile,
    #[arg(long)]
    pub armor: bool,
    #[arg(long)]
    pub classification: Option<String>,
    /// Advisory expiry date (YYYY-MM-DD); not enforced by any software
    #[arg(long)]
    pub expires: Option<String>,
    #[arg(long)]
    pub allow_unrecoverable: bool,
    /// Do not add your own recipient
    #[arg(long)]
    pub no_self: bool,
    #[arg(short = 'o', long, default_value = ".")]
    pub out: PathBuf,
    /// Print the passphrase as a QR code too
    #[arg(long)]
    pub qr: bool,
    /// Timed release: window after first open, e.g. 90s, 10m, 6h, 3d
    #[arg(long)]
    pub expire_after: Option<String>,
    /// Release service base URL (or settings.release_service)
    #[arg(long)]
    pub release_service: Option<String>,
}

pub fn run(a: Args) -> anyhow::Result<()> {
    let ks = crate::store();
    let settings = ks.settings()?;
    let mut recipients = Vec::new();
    for r in &a.recipients {
        recipients.push(Recipient::parse(r)?);
    }
    let log_n = match a.kdf_profile { KdfProfile::Default => SCRYPT_DEFAULT_LOG_N, KdfProfile::High => SCRYPT_HIGH_LOG_N, KdfProfile::Test => 10 };
    let mode = if a.passphrase {
        let kdf = if a.argon2id {
            Kdf::Argon2id(match a.kdf_profile { KdfProfile::High => Profile::Desktop, _ => Profile::Compat })
        } else {
            Kdf::Scrypt { log_n }
        };
        let list = match a.words { Words::Eff => WordList::Eff, Words::Bip39 => WordList::Bip39 };
        Mode::Passphrase { list, words: a.word_count, kdf }
    } else {
        Mode::Recipients(recipients)
    };
    let release = match a.expire_after {
        Some(w) => {
            let window_secs = super::parse_window(&w)?;
            let service = a.release_service.or(settings.release_service.clone())
                .ok_or_else(|| anyhow::anyhow!("--expire-after needs --release-service or settings.release_service"))?;
            let token = std::env::var("SEALDROP_RELEASE_TOKEN").ok().or(settings.release_token.clone())
                .ok_or_else(|| anyhow::anyhow!("set SEALDROP_RELEASE_TOKEN or settings.release_token"))?;
            Some(ReleaseConfig { service, token, window_secs })
        }
        None => None,
    };
    let res = seal(&ks, SealRequest {
        input: a.input, out_dir: a.out, mode, include_self: !a.no_self, allow_unrecoverable: a.allow_unrecoverable,
        armor: a.armor || settings.armor, classification: a.classification, expires: a.expires, release,
    }, &super::StderrProgress)?;

    println!("sealed: {}", res.package.display());
    println!("manifest: {}", res.manifest.display());
    println!("package id: {}", res.manifest_doc.package_id);
    println!("ciphertext sha256: {}", res.manifest_doc.ciphertext.sha256);
    if let Some(r) = &res.manifest_doc.release {
        println!("Timed release: {} after first open, enforced by {}", human(r.window_secs), r.service);
        println!("This does not protect the contents once decrypted.");
    }
    if let Some(p) = &res.passphrase {
        println!("passphrase: {}", p.joined());
        println!("entropy: {:.1} bits — send it on a different channel from the file", p.entropy_bits);
        if a.qr {
            let code = qrcode::QrCode::new(p.joined().as_bytes())?;
            println!("{}", code.render::<qrcode::render::unicode::Dense1x2>().quiet_zone(true).build());
```

```rust
// clock.rs
use std::sync::atomic::{AtomicI64, Ordering};

pub trait Clock: Send + Sync {
    fn now_rfc3339(&self) -> String;
    fn now_unix(&self) -> i64;
}

pub struct SystemClock;
impl Clock for SystemClock {
    fn now_rfc3339(&self) -> String { chrono::Utc::now().format("%Y-%m-%dT%H:%M:%SZ").to_string() }
    fn now_unix(&self) -> i64 { chrono::Utc::now().timestamp() }
}

pub struct FixedClock(AtomicI64);
impl FixedClock {
    pub fn new(rfc3339: &str) -> Self {
        let t = chrono::DateTime::parse_from_rfc3339(rfc3339).unwrap().timestamp();
        Self(AtomicI64::new(t))
    }
    pub fn advance_secs(&self, s: i64) { self.0.fetch_add(s, Ordering::SeqCst); }
}
impl Clock for FixedClock {
    fn now_rfc3339(&self) -> String { fmt_unix(self.now_unix()) }
    fn now_unix(&self) -> i64 { self.0.load(Ordering::SeqCst) }
}

pub fn fmt_unix(t: i64) -> String {
    chrono::DateTime::from_timestamp(t, 0).unwrap().format("%Y-%m-%dT%H:%M:%SZ").to_string()
}
```

```rust
// ratelimit.rs — per-IP token bucket, in memory.
use std::collections::HashMap;
use std::net::IpAddr;
use std::sync::atomic::{AtomicU32, Ordering};
use std::sync::Mutex;
use std::time::Instant;

pub struct Limiter {
    capacity: AtomicU32,
    refill_per_sec: f64,
    buckets: Mutex<HashMap<IpAddr, (f64, Instant)>>,
}

impl Limiter {
    pub fn new(capacity: u32, refill_per_sec: f64) -> Self {
        Self { capacity: AtomicU32::new(capacity), refill_per_sec, buckets: Mutex::new(HashMap::new()) }
    }
    pub fn set_capacity(&self, c: u32) { self.capacity.store(c, Ordering::SeqCst); }
    /// Returns true if the request is allowed.
    pub fn allow(&self, ip: IpAddr) -> bool {
        let cap = self.capacity.load(Ordering::SeqCst) as f64;
        let mut b = self.buckets.lock().unwrap();
        let now = Instant::now();
        let (tokens, last) = b.entry(ip).or_insert((cap, now));
        *tokens = (*tokens + now.duration_since(*last).as_secs_f64() * self.refill_per_sec).min(cap);
        *last = now;
        if *tokens >= 1.0 { *tokens -= 1.0; true } else { false }
    }
}
```

```rust
// routes.rs
use axum::extract::{ConnectInfo, Path, Request, State};
use axum::http::{HeaderMap, StatusCode};
use axum::middleware::Next;
use axum::response::{IntoResponse, Response};
use axum::Json;
use serde::{Deserialize, Serialize};
use std::net::{IpAddr, SocketAddr};

use crate::app::AppState;
use crate::clock::fmt_unix;

pub async fn healthz() -> &'static str { "ok" }

pub async fn rate_limit(State(st): State<AppState>, req: Request, next: Next) -> Response {
    let ip: IpAddr = req.extensions().get::<ConnectInfo<SocketAddr>>().map(|c| c.0.ip()).unwrap_or(IpAddr::from([127, 0, 0, 1]));
    if !st.limiter.allow(ip) {
        return (StatusCode::TOO_MANY_REQUESTS, "rate limited").into_response();
    }
    next.run(req).await
}

fn bearer(headers: &HeaderMap) -> Option<String> {
    headers.get("authorization")?.to_str().ok()?.strip_prefix("Bearer ").map(|s| s.trim().to_string())
}

#[derive(Deserialize)]
pub struct DepositBody { k_release: String, window_secs: u64, unlock_token_hash: String, package_sha256: String }

pub async fn deposit(State(st): State<AppState>, Path(id): Path<String>, headers: HeaderMap, body: Option<Json<DepositBody>>) -> Response {
    let Some(tok) = bearer(&headers) else { return StatusCode::UNAUTHORIZED.into_response() };
    if !st.db.token_valid(&tok).unwrap_or(false) { return StatusCode::UNAUTHORIZED.into_response(); }
    let Some(Json(b)) = body else { return (StatusCode::BAD_REQUEST, "invalid body").into_response() };
    if id.len() > 64 || !id.chars().all(|c| c.is_ascii_alphanumeric() || c == '-') { return (StatusCode::BAD_REQUEST, "bad id").into_response(); }
    if b.k_release.len() > 64 || b.unlock_token_hash.len() != 64 || b.package_sha256.len() > 64 || b.window_secs == 0 || b.window_secs > 366 * 86_400 {
        return (StatusCode::BAD_REQUEST, "bad fields").into_response();
    }
    match st.db.insert_release(&id, &b.k_release, b.window_secs as i64, &b.unlock_token_hash, &b.package_sha256, &st.clock.now_rfc3339()) {
        Ok(true) => StatusCode::CREATED.into_response(),
        Ok(false) => (StatusCode::CONFLICT, "release exists").into_response(),
        Err(_) => StatusCode::INTERNAL_SERVER_ERROR.into_response(),
    }
}

#[derive(Deserialize)]
pub struct UnlockBody { unlock_token: String }

#[derive(Serialize)]
pub struct UnlockResponse { k_release: String, first_unlock: String, expires_at: String }

pub async fn unlock(State(st): State<AppState>, Path(id): Path<String>, body: Option<Json<UnlockBody>>) -> Response {
    let Some(Json(b)) = body else { return (StatusCode::BAD_REQUEST, "invalid body").into_response() };
    let Ok(Some(row)) = st.db.get_release(&id) else { return StatusCode::NOT_FOUND.into_response() };
    let raw = match base64::Engine::decode(&base64::prelude::BASE64_STANDARD_NO_PAD, &b.unlock_token) {
        Ok(r) => r,
        Err(_) => return StatusCode::FORBIDDEN.into_response(),
    };
    if sealdrop_core::hashing::sha256_hex(&raw) != row.unlock_token_hash { return StatusCode::FORBIDDEN.into_response(); }
    let now = st.clock.now_unix();
    let (first, expires_at, expires_unix) = match (&row.first_unlock, &row.expires_at, row.expires_unix) {
        (Some(f), Some(e), Some(eu)) => (f.clone(), e.clone(), eu),
        _ => {
            let eu = now + row.window_secs;
            let f = fmt_unix(now);
            let e = fmt_unix(eu);
            let _ = st.db.mark_first_unlock(&id, &f, &e, eu);
            (f, e, eu)
        }
    };
    if now >= expires_unix {
        let _ = st.db.delete_key(&id);
        return (StatusCode::GONE, "release window has passed").into_response();
    }
    let Some(k) = row.k_release else { return (StatusCode::GONE, "release window has passed").into_response() };
    let _ = st.db.bump_unlock_count(&id);
    Json(UnlockResponse { k_release: k, first_unlock: first, expires_at }).into_response()
}

pub async fn receipt(State(st): State<AppState>, Path(id): Path<String>, headers: HeaderMap) -> Response {
    let Some(tok) = bearer(&headers) else { return StatusCode::UNAUTHORIZED.into_response() };
    if !st.db.token_valid(&tok).unwrap_or(false) { return StatusCode::UNAUTHORIZED.into_response(); }
    let Ok(Some(row)) = st.db.get_release(&id) else { return StatusCode::NOT_FOUND.into_response() };
    let r = sealdrop_core::release::Receipt {
        release_id: row.release_id, package_sha256: row.package_sha256, first_unlock: row.first_unlock,
        expires_at: row.expires_at, unlock_count: row.unlock_count as u64, service_key: st.signer.pk.to_base64(),
    };
    match sealdrop_core::release::sign_receipt(&r, &st.signer.sk, &st.signer.pk) {
        Ok(s) => Json(s).into_response(),
        Err(_) => StatusCode::INTERNAL_SERVER_ERROR.into_response(),
    }
}
```

```rust
use std::path::PathBuf;
use std::sync::Arc;

use clap::{Parser, Subcommand};
use sealdrop_release::app::{build, AppState};
use sealdrop_release::clock::SystemClock;
use sealdrop_release::db::Db;

#[derive(Parser)]
#[command(name = "sealdrop-release", version, about = "Key-release service for sealdrop timed release")]
struct Cli { #[command(subcommand)] cmd: Cmd }

#[derive(Subcommand)]
enum Cmd {
    /// Create the service signing key (service.key / service.pub in --dir)
    Keygen { #[arg(long, default_value = ".")] dir: PathBuf },
    /// Create a deposit token for a sender; prints it once
    Token { #[command(subcommand)] cmd: TokenCmd },
    /// Run the HTTP service (terminate TLS in front of it)
    Serve {
        #[arg(long, default_value = "127.0.0.1:8787")] listen: String,
        #[arg(long, default_value = "releases.db")] db: String,
        #[arg(long, default_value = ".")] dir: PathBuf,
        #[arg(long, default_value_t = 60)] rate_capacity: u32,
        #[arg(long, default_value_t = 90)] retention_days: i64,
    },
}

#[derive(Subcommand)]
enum TokenCmd { New { name: String, #[arg(long, default_value = "releases.db")] db: String } }

fn load_signer(dir: &PathBuf) -> anyhow::Result<minisign::KeyPair> {
    let sk = minisign::SecretKeyBox::from_string(&std::fs::read_to_string(dir.join("service.key"))?)?.into_unencrypted_secret_key()?;
    let pk = minisign::PublicKeyBox::from_string(&std::fs::read_to_string(dir.join("service.pub"))?)?.into_public_key()?;
    Ok(minisign::KeyPair { pk, sk })
}

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    tracing_subscriber::fmt().with_env_filter(tracing_subscriber::EnvFilter::from_default_env()).init();
    match Cli::parse().cmd {
        Cmd::Keygen { dir } => {
            let kp = minisign::KeyPair::generate_unencrypted_keypair()?;
            std::fs::write(dir.join("service.key"), kp.sk.to_box(Some("sealdrop-release"))?.into_string())?;
            std::fs::write(dir.join("service.pub"), kp.pk.to_box()?.into_string())?;
            println!("service key: {}", kp.pk.to_base64());
        }
        Cmd::Token { cmd: TokenCmd::New { name, db } } => {
            let db = Db::open(&db)?;
            println!("{}", db.create_token(&name)?);
            eprintln!("store this token securely; it is shown once");
        }
        Cmd::Serve { listen, db, dir, rate_capacity, retention_days } => {
            let db = Db::open(&db)?;
            let state = AppState::new(db, Arc::new(SystemClock), load_signer(&dir)?, rate_capacity);
            let sweeper = state.clone();
            tokio::spawn(async move {
                let mut tick = tokio::time::interval(std::time::Duration::from_secs(60));
                loop {
                    tick.tick().await;
                    if let Ok(n) = sweeper.db.sweep_expired_unix(sweeper.clock.now_unix(), retention_days) {
                        if n > 0 { tracing::info!(deleted_keys = n, "sweep"); }
                    }
                }
            });
            let app = build(state).into_make_service_with_connect_info::<std::net::SocketAddr>();
            let listener = tokio::net::TcpListener::bind(&listen).await?;
            tracing::info!(%listen, "sealdrop-release listening");
            axum::serve(listener, app).await?;
        }
    }
    Ok(())
}
```

```rust
#[tauri::command]
pub fn seal(app: AppHandle, req: SealArgs) -> Result<SealOut, String> {
    use sealdrop_core::seal::{seal, Kdf, Mode, ReleaseConfig, SealRequest};
    let ks = store();
    let settings = ks.settings().map_err(s)?;
    let log_n = if req.kdf_profile == "high" { sealdrop_core::crypt::SCRYPT_HIGH_LOG_N } else { sealdrop_core::crypt::SCRYPT_DEFAULT_LOG_N };
    let mode = if req.passphrase {
        let list = if req.words == "bip39" { sealdrop_core::passphrase::WordList::Bip39 } else { sealdrop_core::passphrase::WordList::Eff };
        let kdf = if req.argon2id {
            Kdf::Argon2id(if req.kdf_profile == "high" { sealdrop_core::argon2id::Profile::Desktop } else { sealdrop_core::argon2id::Profile::Compat })
        } else { Kdf::Scrypt { log_n } };
        Mode::Passphrase { list, words: 0, kdf }
    } else {
        let mut v = Vec::new();
        for r in &req.recipients { v.push(sealdrop_core::crypt::Recipient::parse(r).map_err(s)?); }
        Mode::Recipients(v)
    };
    let release = match req.expire_after_secs {
        Some(w) => Some(ReleaseConfig {
            service: settings.release_service.clone().ok_or("Set the release service URL in Settings first")?,
            token: settings.release_token.clone().ok_or("Set the release deposit token in Settings first")?,
            window_secs: w,
        }),
        None => None,
    };
    let res = seal(&ks, SealRequest { input: req.input.into(), out_dir: req.out_dir.into(), mode, include_self: req.include_self,
        allow_unrecoverable: req.allow_unrecoverable, armor: req.armor || settings.armor, classification: req.classification,
        expires: req.expires, release }, &EmitProgress(app)).map_err(s)?;
    Ok(SealOut {
        package: res.package.display().to_string(), manifest: res.manifest.display().to_string(),
        package_id: res.manifest_doc.package_id.clone(), ciphertext_sha256: res.manifest_doc.ciphertext.sha256.clone(),
        passphrase: res.passphrase.as_ref().map(|p| p.joined()), entropy_bits: res.passphrase.as_ref().map(|p| p.entropy_bits),
        release: res.manifest_doc.release.map(|r| ReleaseOut { service: r.service, window_secs: r.window_secs }),
    })
}

        PathBuf::from(req.out_dir.ok_or("choose a destination folder")?)

        first_unlock: rep.release.as_ref().map(|u| u.first_unlock.clone()), expires_at: rep.release.map(|u| u.expires_at) })
}

    let ks = store();

    Ok(ReceiptOut { release_id: rec.release_id, first_unlock: rec.first_unlock, expires_at: rec.expires_at, unlock_count: rec.unlock_count, service_key: rec.service_key, saved_to: out })
}
```
